## Part 1 Netlify和Vercel是什么？

Netlify和Vercel都是美国的托管平台，允许用户搭建一些网站前端构建，类似于Github Action的构建功能，两个公司总部均坐落于美国旧金山，市值都在20亿美元之上。两者非常相似，是~~白嫖客~~搭建博客等小项目的不二之选，使用起来操作方式也很相似，那么他们的差异是什么，谁更好用一点呢？

## Part 2 对比双方异同：谁更胜一筹？

| **对比项目** | **Vercel** | **Netlify** |
| --- | --- | --- |
| 最低使用费用 | FREE | FREE，但是容易产生账单 |
| 构建支持的平台 | Github GitLab等 | Github Azure DevOps等 |
| 免费限制的流量 | 不限 | 100 GBit/mo |
| 免费构建时间限制 | 1000 分钟/mo | 300 分钟/mo |
| 国内访问速度 | 快 | 快 |
| 免费二级域名 | vercel.app | netlify.app |
| 二级域名国内可访问性 | 无法访问，需要域名 | 可以直接访问 |
| 站点数量上限 | Unknown | 500个 |
| 绑定域名 | 可以 | 可以 |
| 注册相关 | 可以邮箱注册和Github等第三方注册登录，不容易封号，可能会判定滥用 | 使用邮箱注册和其他第三方注册，国内大概率注册就封号，无法自动解除，需要人工申诉 |

## Part 3 总结

对比下来Vercel和Netlify有很大的相同点，也有明显的差异，对于我而言，我觉得Netlify更胜一筹，毕竟Vercel不绑定域名就访问不了vercel.app的二级域名，无形地增加了成本。虽然Netlify容易封号，但是申诉之后1天就解封了，处理速度很快，而且100Gbit/mo像这种小博客可以说是绰绰有余了。所以总得来说,还是比较推荐Netlify的。但是如果有一个自己的域名的话，Vercel的免费限制相比之下也是更少的，还需要读者自己权衡。
