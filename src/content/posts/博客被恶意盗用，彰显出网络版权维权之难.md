# 起因

2024年8月11日，我在网上冲浪时，使用Google时，搜索了“LinYunLink”，突然发现了一个别样的站点——hzydyswkj.com。至此本文的故事就出现了……

我点进了该网站，发现这个网站盗用了我们的站点，直接复制了所有内容，样式都没有改变，单纯将简体中文翻译成了台湾繁体中文，于是我对比了HTML：

```html
<!-- saved from url=(0027)https://www.linyunlink.top/ -->
<html>

<head>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
    <meta name="color-scheme" content="light dark">
</head>

<body>
    <!-- 下列HTML元素完全相同省略 -->
</body>
    
```

```html
<!-- saved from url=(0022)https://hzydyswkj.com/ -->
<html>

<head>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
    <meta name="color-scheme" content="light dark">
</head>

<body>
    <!-- 下列HTML元素完全相同省略 -->
</body>
```

很好，中间部分几乎完全相同。我们查询了对方网站的Whois，同时在没用的小废鼠的帮助下，发现对方信息非常隐蔽，使用了PHP，植入了Google广告，疑似每个月更换一个博客。其DNS服务器使用的是Cloudflare。于是我们提起了投诉，但是并没有下文了。

# 后续

截至目前2024年8月11日，该域名已经无法访问，显示重定向过多，域名也要在10月过期，如果有续费的话，说明还有人操纵，但是现在什么也不知道……

总之，似乎是胜利了，但实际上根本没有维权——根本没法维权，对面是谁都不知道。方便的互联网有时也不方便……
